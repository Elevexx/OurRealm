## RECORDED ADDITION (Jul 25, 2026 — NOT authorized for implementation yet): Stealth-Only Copyright Hold, Attention Tickets, Rights-Review Strikes, 30-Day Sound Restrictions
Belongs to Sound Admin / Copyright Tool / moderation / support-ticket / audit phases (Increments E/G). Full founder spec received Jul 25 — key points:
- `FOUNDER_COPYRIGHT_HOLD` permission bound to immutable founder account id (never username text/client roles). Stealth-only founder moderation menu on every eligible post (Edit for Moderation, Lock Private — Copyright Proof Required, Open Copyright Case, Remove/Replace Audio, Internal Note, View User Rights History) with pre-lock confirmation dialog (owner, IDs, reason, strike toggle default-on, current qualifying-strike count, ⚠️ third-strike 30-day warning; server-enforced regardless of client).
- `PRIVATE_COPYRIGHT_HOLD` status: atomic → private + removed from all public surfaces/playback/reuse + evidence preserved + internal record + owner-only "⚠️ ATTENTION NEEDED" notice (opens the exact linked ticket) + auto support ticket (one per moderation event, dedupe on retries, full linked IDs, evidence upload) + optional pending Rights Review Strike. Never framed as final legal determination.
- Rights Review Strikes: full record schema (status pending/active/removed/expired/overturned, proof status, decision trail, audit). Reports alone ≠ strike. 3 active unapproved strikes ⇒ automatic server-side 30-day Sound-use restriction (blocks upload/original-audio publish/attach to image/video/replace-audio/realm-portal-nexus audio assignment; allows listening, playlists view, removals, ticket responses, evidence, appeals, no-audio publishing). Restriction notice with dates/links/appeal. Configurable policy (threshold, duration, pending-count rule, auto-lift, override+reason) in validated moderation config — no hardcoding.
- Approval recalculates count; below threshold auto-lifts by default (admin may keep with reason+end date). Rejection keeps strike + post private; no accidental duplicate strikes per moderation event. Server-side automatic expiration checked at every restricted action.
- Admin section "RIGHTS REVIEW STRIKES & SOUND RESTRICTIONS" in Sounds Control Center + Copyright Tool; support-page filters (Copyright Proof Required … Resolved) with cross-links to post/sound/user/case/strike/restriction/evidence/audit.
- Security: server-side everything; no self-approval/self-unstrike; no stale-client or legacy-route bypass; idempotency + uniqueness constraints; immutable audit log (actor, role, action, targets, case/ticket/strike/restriction IDs, before/after, reason, timestamp, environment, request id).
- Terminology: Private Copyright Hold, Attention Needed, Copyright Proof Required, Rights Review Strike, Sound-Use Restriction, Proof Approved/Rejected, Awaiting Additional Information. Never "proven thief"/"legally guilty"/"confirmed infringement".
- Testing: full founder-access/hold/ticket/strike/restriction/approval/expiration matrix per founder spec §20; 30-point completion report per §21.
